Productivity Dashboard

A modern Productivity Dashboard Web App built using HTML, CSS, and JavaScript to manage daily tasks,track productivity, and visualize performance.

**Features**
- Add, delete, and manage tasks
- Task filtering (Priority, Category, Status)
- Real-time task updates using Local Storage
- Dashboard with:
   Today's Tasks
   Completion Rate
   Focus Time Tracking
   Weekly Progress Chart
- Analytics section with weekly productivity visualization
- Dark Mode support 🌙
- Custom accent color selection
- Responsive design (Mobile + Desktop)

**Tech Stack**
HTML5
CSS3 (Responsive + Dark Mode)
JavaScript (Vanilla JS)
LocalStorage API

**How It Works**
Tasks are stored in LocalStorage
Dashboard auto-updates based on stored data
Completion rate and focus time are calculated dynamically
Weekly charts are generated using JavaScript logic
